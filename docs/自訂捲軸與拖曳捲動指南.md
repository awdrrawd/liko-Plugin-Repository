# 自訂捲軸與拖曳捲動指南

本文件說明如何在 Bondage Club 插件的 DOM UI 中：

1. 保留瀏覽器原生捲軸功能，但將白色捲軸改成符合插件 UI 的主題色。
2. 讓使用者按住清單內容上下拖曳。
3. 避免拖曳後誤觸按鈕、拖曳狀態殘留，以及巢狀捲動區互相搶事件。

實作方式參考 BC-AEE 的 `aee-scroll` 與 `installDragScroll`。PCM 的語言選單也使用相同模型。

## 一、基本 HTML

```html
<div class="my-scroll-area">
  <button type="button">AUTO</button>
  <button type="button">繁體中文</button>
  <button type="button">简体中文</button>
  <button type="button">English</button>
  <button type="button">Deutsch</button>
  <button type="button">Français</button>
  <button type="button">Русский</button>
  <button type="button">Українська</button>
</div>
```

捲動元素本身必須同時具備：

- 可被限制的高度，例如 `max-height` 或固定 `height`。
- `overflow-y: auto`。
- 內容總高度大於可視高度。

如果 `scrollHeight <= clientHeight`，代表內容沒有溢出，自然不會產生捲動。

## 二、將原生白色捲軸改成主題色

不建議另外製作一個假滑軌來同步 `scrollTop`。原生捲軸已處理滑鼠、觸控板、鍵盤及無障礙操作，只需要修改外觀。

```css
.my-scroll-area {
  max-height: 190px;
  overflow-y: auto;

  /* Firefox */
  scrollbar-width: thin;
  scrollbar-color: #9a6cff rgba(0, 0, 0, 0.35);

  /* 手機原生垂直捲動 */
  touch-action: pan-y;
  overscroll-behavior: contain;
}

/* Chromium / Edge / Safari */
.my-scroll-area::-webkit-scrollbar {
  width: 10px;
}

.my-scroll-area::-webkit-scrollbar-track {
  background: rgba(0, 0, 0, 0.35);
  border-radius: 7px;
}

.my-scroll-area::-webkit-scrollbar-thumb {
  background: #8258dc;
  border-radius: 7px;
}

.my-scroll-area::-webkit-scrollbar-thumb:hover {
  background: #9a6cff;
}
```

這仍是瀏覽器原生捲軸，不是模擬滑塊。它可以正常使用滑鼠拖曳，也不會留下額外的滑軌 DOM。

## 三、讓使用者按住內容拖曳

桌面瀏覽器預設不會因為按住清單內容而捲動。以下函式加入 AEE 式內容拖曳：

```js
function installDragScroll(area) {
  let drag = null;
  let suppressClick = false;

  const onPointerDown = event => {
    if (!event.isPrimary || event.button !== 0) return;
    if (area.scrollHeight <= area.clientHeight + 1) return;

    // range、輸入框等控制項應保留自己的拖曳行為。
    const target = event.target instanceof Element ? event.target : null;
    if (target?.closest('input[type="range"], textarea, select, [contenteditable="true"]')) return;

    drag = {
      pointerId: event.pointerId,
      startX: event.clientX,
      startY: event.clientY,
      startScrollTop: area.scrollTop,
      dragging: false,
    };
  };

  const onPointerMove = event => {
    if (!drag || drag.pointerId !== event.pointerId) return;

    const dx = event.clientX - drag.startX;
    const dy = event.clientY - drag.startY;

    if (!drag.dragging) {
      // 小幅移動仍視為普通點擊；橫向動作也不啟動垂直拖曳。
      if (Math.abs(dy) < 6 || Math.abs(dy) <= Math.abs(dx)) return;

      drag.dragging = true;
      area.classList.add('dragging');

      try {
        area.setPointerCapture(event.pointerId);
      } catch {
        // 元素在畫面切換時被移除，不需要中斷其他程式。
      }
    }

    event.preventDefault();

    // 必須使用按下當時的 scrollTop 和總位移。
    // 不要在每次 move 中重設起點，否則容易產生跳動或方向錯亂。
    area.scrollTop = drag.startScrollTop - dy;
  };

  const finish = event => {
    if (!drag || drag.pointerId !== event.pointerId) return;

    const wasDragging = drag.dragging;
    drag = null;
    area.classList.remove('dragging');

    if (!wasDragging) return;

    // pointerup 後瀏覽器通常還會送出 click。
    // 只阻止這一次 click，避免拖完清單卻誤選某個項目。
    suppressClick = true;
    window.setTimeout(() => {
      suppressClick = false;
    }, 0);
  };

  const suppressDraggedClick = event => {
    if (!suppressClick) return;
    event.preventDefault();
    event.stopImmediatePropagation();
    suppressClick = false;
  };

  area.addEventListener('pointerdown', onPointerDown, true);
  area.addEventListener('pointermove', onPointerMove, {
    capture: true,
    passive: false,
  });
  area.addEventListener('pointerup', finish, true);
  area.addEventListener('pointercancel', finish, true);
  area.addEventListener('click', suppressDraggedClick, true);

  // 插件卸載或 UI 重建時呼叫，避免重複綁定。
  return () => {
    drag = null;
    area.classList.remove('dragging');
    area.removeEventListener('pointerdown', onPointerDown, true);
    area.removeEventListener('pointermove', onPointerMove, true);
    area.removeEventListener('pointerup', finish, true);
    area.removeEventListener('pointercancel', finish, true);
    area.removeEventListener('click', suppressDraggedClick, true);
  };
}

const scrollArea = document.querySelector('.my-scroll-area');
const removeDragScroll = installDragScroll(scrollArea);

// UI 關閉、重建或插件卸載時：
// removeDragScroll();
```

拖曳中的游標樣式：

```css
.my-scroll-area.dragging,
.my-scroll-area.dragging * {
  cursor: grabbing !important;
  user-select: none !important;
  -webkit-user-select: none !important;
}
```

## 四、為什麼不能按下時立刻進入拖曳

如果在 `pointerdown` 時立刻加入 `dragging`，普通點擊與拖曳就無法區分，按鈕、語言選項等內容會很難操作。

正確順序是：

1. `pointerdown` 只記錄起點。
2. `pointermove` 的垂直距離超過門檻後才進入拖曳。
3. 拖曳期間才呼叫 `preventDefault()`。
4. `pointerup` 與 `pointercancel` 都必須立即清除狀態。
5. 只有真的拖曳過，才阻止隨後的一次 `click`。

這可以避免「握拳時不動、放開後才移動」或「放開後仍維持握拳」等狀態錯亂。

## 五、巢狀捲動區的事件衝突

如果下拉選單位於另一個可拖曳面板內，父層與子層不能各自同時處理同一個指標。

父層的 `pointerdown` 必須排除子捲動區：

```js
parent.addEventListener('pointerdown', event => {
  const target = event.target instanceof Element ? event.target : null;

  if (target?.closest('.my-scroll-area')) return;

  // 父層自己的拖曳初始化……
});
```

更適合大型 UI 的做法是像 AEE 一樣，只在共同根元素安裝一次事件，再找距離事件目標最近的捲動區：

```js
const area = target?.closest('.my-scroll-area');
if (!area) return;
```

不要同時對父容器和下拉選單各安裝一套慣性拖曳。兩套程式可能互相搶奪 `pointer capture`，導致拖曳方向、游標及放開狀態錯亂。

## 六、常見錯誤

### 自製一條假的滑軌

假的滑軌需要自行同步尺寸、位置、滾輪、觸控、鍵盤與無障礙操作，也容易在選單收起後殘留。除非 UI 有原生捲軸完全無法實現的需求，否則應保留原生捲軸，只修改 CSS。

### 使用 `touch-action: none`

`touch-action: none` 會停用瀏覽器原生觸控捲動。一般垂直清單應使用：

```css
touch-action: pan-y;
```

### 只監聽 `pointerup`

裝置切換、元素移除或瀏覽器取消手勢時可能只送出 `pointercancel`。兩者必須使用同一個清理函式。

### 拖曳結束後長時間阻止 click

只應阻止緊接在拖曳後的那一次 click。若使用長時間旗標，使用者放開後會無法正常選擇項目。

### 在 `pointermove` 中做慣性延遲

簡單下拉選單不需要慣性動畫。慣性狀態若沒有完整管理，很容易出現放開後才開始移動的錯覺。AEE 式做法直接更新 `scrollTop`，放開即停止。

## 七、建議測試項目

至少測試以下行為：

- 滑鼠滾輪可以捲動。
- 可以直接拖曳右側原生滑塊。
- 按住內容向上／向下拖曳可以捲動。
- 小幅移動後放開仍能正常點擊選項。
- 真正拖曳後不會誤觸選項。
- 放開及取消手勢後，`dragging` class 都會消失。
- 下拉選單關閉後不會殘留滑軌或拖曳狀態。
- 手機可以用單指原生垂直滑動。
- 父面板可拖曳時，子選單不會同時帶動父層。
