# Liko - Kaomoji v1.2.0

點擊聊天室的笑臉按鈕開啟顏文字面板。登入提示可點擊立即關閉，或等待六秒自動淡出。

## 插入與操作

- 顏文字插入聊天框目前游標位置；已選取文字會被替換。前方不是空白時自動補一個空格。
- 原有自動發送、自動關閉設定繼續生效。
- 面板縮放使用 Pointer Events，支援滑鼠、觸控與觸控筆。
- 玩家設定載入後，恢復上次按鈕列的收合狀態；後續切換會保存。

## 分組備份與匯入

面板標題列新增兩個按鈕：

- **↓ 匯出**：下載 `liko-kaomoji-groups.json`，包含自訂分組與顏文字。
- **↑ 匯入**：選取匯出格式的 JSON（最多 2 MiB）。同名分組合併，不同名分組新增，重複顏文字去重；不刪除既有分組。

此備份不含收藏、最近使用或面板設定。自訂分組仍存於目前裝置的 localStorage，跨裝置可手動匯出／匯入。

```json
{
  "format": "liko-kaomoji",
  "version": 1,
  "groups": [
    { "id": "example", "name": "開心", "emotes": ["(≧▽≦)"] }
  ]
}
```

匯入不沿用外部 ID，以名稱合併；新分組產生新的 ID。檔案格式或寫入失敗時保留原資料。

## 資料與停用

舊 DB 分組與最近使用資料只有在 localStorage 寫入成功後才清除 DB 來源；旧版本地帳號設定搬到 DB 後仍保留本地備份，因同步 API 不提供伺服器確認回執。

`window.Liko.Kaomoji.Destroy()` 儲存尚待處理的設定，取消等待與計時器、移除全域事件和 UI，並透過 SDK 的 `unload()` 卸載。重載不會累積舊實例的操作監聽器。

驗證：在儲存庫根目錄執行 `node scripts/test-kaomoji.cjs`。
