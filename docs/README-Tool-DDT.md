# TOOL 2.3.12 與 DDT 0.4.0

## TOOL

- 人物互動格只染色目前功能的可選物品，不查詢遮擋／衣物阻擋、不以紅色表示遮擋；清除 Craft 時無 Craft 的道具保持無色且不可選。人物尺寸監聽改為下一幀合併更新，未變更的尺寸不重寫；捲軸監聽採增量增減，樣式變更不重建整套 ResizeObserver 訂閱。

- 清除訂製物品沿用共用清單／人物選擇器、標題列切換按鈕與模式記憶；以裝備組識別複選，只列出具有 Craft 的物品，確認時重新檢查目標與互動權限。

- 主選單、子頁與單欄物品清單的捲軸對齊工具箱右緣，內容統一使用 10px 水平邊距。雙欄左側清單保留內部捲軸空間，描述輸入框保留文字邊距，避免滑塊覆蓋內容。

- `setupToolScrollbars` 統一繪製主選單、子頁、Craft 物品欄／側欄及 textarea 的 DOM 捲軸；隱藏原生捲軸外觀，保留原生滾輪／觸控捲動。共用滑軌支援拖曳、點擊翻頁及方向鍵／Home／End／PageUp／PageDown，顏色沿用主題。內容、視窗尺寸與轉場變化會同步更新；無溢出或非作用頁面隱藏，卸載時移除 observer 與元件。

- 主檔以 `SECTION 01`～`15` 分區：生命週期 → 資源／語系 → 設定 → 共用遊戲操作 → 主題 CSS → 工具箱 → 選擇器／預覽 → Craft → Undo → 外觀操作 → 顯示／RP → 功能 Hook → 整合入口 → 啟動與卸載。狀態與所屬功能相鄰，圖示及共用按鈕放在使用端之前。
- 防重複判定位於 IIFE 開頭，在 `AbortController`／集合建立之前。RP 隱藏快捷鍵改為由 `initialize()` 登入後註冊；檔案末尾是唯一啟動入口。測試涵蓋重複注入不新增資源，以及卸載後可重新載入。

- 編輯功能排序／顯示時，短按圓圈切換顯示，長按 400ms 後拖移排序（包含從圓圈開始拖移）。長按前移動超過 8px 取消點擊；拖移、取消手勢及遺失捕獲不切換隱藏狀態。
- 介面提示、Craft 訊息、Undo 比較、功能說明與強調色名稱统一使用 `LANG`／`t()`；中英文鍵值與替換參數由回歸測試檢查。

- UI 建構集中為 `createPanel`（頁面堆疊／清理）、`makeFooter`（取消與排列）、`makeToolButton`／`makeButtonRow`（按鈕）及 `requestButtons`（通用選單，角色選擇也沿用）。完成時明確呼叫 `popPage`，不覆寫 DOM `remove()`。
- 單項／批量 Craft 共用 `createCraftFields` 與 `craftForEdit`；功能開關共用 `toggleSetting` 的保存、套用、廣播與刷新流程。靜態 CSS 集中於 `injectLtStyles`，JS 僅保留位置、尺寸、層級與使用者色彩等動態值。
- 移除舊彈窗、已停用控制項 CSS、重複表單與全域 UI 刷新橋接；Undo 預覽清理由頁面生命週期負責，不再監看整個 document。保留必要的 R132／ECHO 相容邏輯與舊設定遷移。

- 所有 TOOL 偏好以一般物件保存在 `Player.ExtensionSettings.LikoTOOL`，不壓縮。包含功能開關、RP 狀態、`theme`、`buttonOrder`、`menuLayout`、`panelPosition`、`itemViewMode`。舊壓縮字串與瀏覽器偏好自動遷移；已有帳號設定優先。`OnlineSharedSettings` 只保留徽章所需的廣播副本。Craft 匯出維持遊戲原生編碼。
- 人物模式圖示使用 2×2 格子；清單／人物模式跨物品選擇頁共用記憶，重新登入也保留。
- 批量上鎖在 DOGS 註冊 `DeviousPadlock` 後自動列出 Devious，圖片使用 jsDelivr。沿用插件的 `InventoryLock` hook 與權限檢查；未載入插件不偽造鎖資產。[DOGS 上鎖實作](https://github.com/FurryZoi/Devious-Obligate-Great-Stuff/blob/main/src/modules/deviousPadlock.ts)。

- Undo 每位角色最多 **30 筆**，留在本次頁面工作階段的記憶體中。總共最多保留 100 位角色，超過時移除最久沒有新快照的角色。
- 開啟 Undo 面板時固定快照清單。之後進來的新紀錄不會改變正在看的內容，也不會因套用舊快照而刪除新紀錄。
- 差異摘要以裝備組為單位，顯示相較目前外觀的「新增／移除／修改」數量；不是逐欄位差異。
- 預覽切換快照時才重建角色外觀，繪製仍定期更新。
- 主選單標題列依序為調色（原太陽圖示）、齒輪編輯、關閉。齒輪使用提供的 SVG 路徑，改用 `currentColor` 隨標題列配色。齒輪切換編輯模式，動作格與開關均可用滑鼠／觸控拖移排序；圓形按鈕切換顯示／隱藏，實心亮起表示顯示，中空表示隱藏。隱藏項目在編輯時呈灰色，退出編輯後只顯示未隱藏項目，順序與顯示設定保存在本機。隱藏開關不會停用該功能。
- `heightFix`（拉高視角）與 `heightLock`（固定身高比例）是兩個獨立開關。前者只在互動畫面的 `CharacterAppearanceYOffset` 消除 `HeightModifier` 位移，不干涉資產建構使用的 `IgnoreUpButton=true` 路徑；後者使用 `DrawCharacter` 的原生顯示參數，讓人物與 `DialogGetCharacterZone` 的繪製／點擊共同使用比例 1。兩者一起啟用時，以標準 500×1000 視圖呈現頭到腳，避免只修改格子寬高造成錯位。角色本身的 `HeightRatio`／`HeightModifier` 不被改寫，聊天室一般繪製不受影響。工具箱人物預覽使用相同的顯示轉換；回滾預覽使用完整標準視圖。舊 `heightFix` 設定獨立保留，只從舊 `heightLock` 遷移固定比例設定。
- 解除拘束與批量／單項屬性編輯的物品選擇器可從標題列切換清單／人物互動格，SVG 顯示目前的模式。複選以裝備組識別，切換模式不丟失選取；空格灰色、有物品黃色、受阻紅色、已選藍色。人物模式只顯示人物與互動格，按內容區可用寬高等比例縮放，不附說明／清單，也不產生捲軸；沒有原生格子的物品需切回清單選取。
- 上鎖選擇器以三欄圖片＋名稱呈現，以鎖的內部名稱識別選取項目。
- 屬性編輯先選玩家，再用底欄選擇批量或單項。單項編輯於右侧延展面板，預填名稱／描述／私有；保存保留其他 Craft 欄位，作者改為自己，不退出編輯。匯出目前表單內容，使用原生 Craft 單件匯入所用的 `LZString.compressToBase64(JSON.stringify(craft))` 格式，不會額外保存角色或占用 Craft 欄位。
- 所有子頁都有位於底欄最右側的「取消」，退出整個功能、結算未完成的選擇器並回到主選單，工具箱保持開啟。標題列返回鍵只退上一層；單項編輯右側面板開啟時，先收起側欄。單項編輯底欄依序為確定、匯出、取消，側欄開啟時不重複顯示頁面底欄。取消不撤回已確認保存的修改。
- 子頁各自持有捲動容器，只有最上層能互動。批量表單與其他子頁使用相同堆疊，滑入時保留下層，返回鍵回到原選取；延後聚焦並使用 `preventScroll`，視口使用 `overflow:clip`，避免轉場觸發水平捲動。返回／關閉會結算選擇器並停止預覽排程。回滾頁移除操作者資訊，預覽自適應剩餘高度；視窗縮放會重新限制工具箱位置。Canvas 樣式與遊戲全域樣式隔離，預覽直接使用 Canvas 2D 上下文，不進入遊戲主畫面座標的 `DrawImageEx` 掛鉤。來源由原生 `DrawCanvasSegment` 擷取並立即複製；只有 SDK 確認 ECHO 已載入且人物畫布寬度為 1000px，才套用水平 +250 偏移。繞過 ECHO 修改的 `DrawCharacterSegment`，避免重複偏移。魔法鎖與 AFC 心鎖使用指定的 jsDelivr 圖片。互動格保留四像素安全邊距。單項編輯右側面板與工具箱寬度同步展開／收納，收納後不可聚焦，尊重減少動畫設定。
- `ChatRoomSync` 等待非同步流程完成後才建立 Undo 基準，離房／卸載後不再掃描。FreeHands 追蹤 Player 實例更換，掛鉤安裝失敗會回滾已安裝部分。
- 無視遮擋先呼叫後續 hook，僅在存在原生 item-block 條件時放行；保留 enclosure 判定。由於原生 API 只回傳 boolean，其他插件與原生遮擋同時回傳 true 的原因無法區分，此功能仍須與相關插件一併實機驗證。
- `window.Liko.Tool.Destroy()` 清理事件、排程、預覽角色、SDK 掛鉤與面板，解除本插件的魔法攔截，移除載入旗標以允許重新載入。它不回復已發送的聊天或已套用的外觀操作。

## DDT

- Pen 標題列 **↶／↷** 可復原／重做，保留最多 **30 步**。只涵蓋 Pen 物件，不涵蓋角色染色、DOM 修改或工具偏好。
- 物件編輯與偏好儲存延後 250ms 合併；面板 change／pointerup 時提早保存。拖移物件完成時立即保存。
- Setting 可選擇「合併匯入」（預設）或「取代匯入」。取代會先確認。每次成功匯入前保留一份本地備份，可用「還原匯入前備份」回復；備份不是多版本歷史。
- 匯入最多 1,000 個物件、檔案最多 2 MiB。格式不合法、空清單或寫入失敗都不會直接取代現有物件。一般編輯若儲存失敗會提示，畫面上的未保存內容仍保留。
- JSON 支援既有 DDT 匯出物件與物件陣列，物件需有有限數值的 x／y；其他數值與文字欄位也會驗證。
- 偵測未開啟或已凍結，且沒有繪製覆寫及逐步回放時，繪製攔截直接執行原函數，省略紀錄處理。
- 拖曳取消不會建立新物件；移動取消會還原起點。
- `window.Liko.DDT.Destroy()` 保存待寫入內容、清理事件與排程、卸載 SDK、移除介面並還原本地 DOM／繪製覆寫及未推送的染色。已明確推送到伺服器的染色不會自動撤回。

控制台 API：`undoPen()`、`redoPen()`、`importPen(json, 'merge' | 'replace')`。復原歷史留在記憶體中，重新載入後不保留；物件與匯入前備份保存在 localStorage。

## 驗證

在儲存庫根目錄執行 `node scripts/test-tool-ddt.cjs`，涵蓋快照容量與獨立性、差異摘要、匯入失敗保留、復原／重做、合併寫入，以及完整腳本的登入前停用與重載。尚未涵蓋真實 BC 繪製及觸控外觀驗證。

`node scripts/test-tool-ui.cjs` 使用 Playwright 與隔離的遊戲 fixture，涵蓋主選單隱藏／恢復及兩類拖移、格子／清單共用複選、Craft 欄位保留與匯出、回滾捲動、三欄上鎖、窄螢幕側欄、非同步同步及 Player 更換。需可解析 `playwright` 套件與已安裝的 Edge；可用 `TOOL_TEST_BROWSER=chrome` 改用 Chrome。截圖輸出至系統暫存目錄；不連線遊戲伺服器。真實角色的姿勢／倒吊／其他插件組合仍需在 R132 實機驗收。
